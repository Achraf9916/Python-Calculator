# ACHRAF CALCULATOR

## Description

ACHRAF CALCULATOR est un projet de calculatrice développé en Python.

Le programme permet d'effectuer différentes opérations mathématiques à travers une interface graphique simple.

## Fonctionnalités

- Addition
- Soustraction
- Multiplication
- Division
- Nombres décimaux
- Pourcentage
- Effacement de l'expression
- Affichage du résultat
- Gestion des erreurs de calcul


## Objectif

Ce projet a été réalisé afin de mettre en pratique mes premières connaissances en programmation et de développer progressivement mes compétences en informatique.
